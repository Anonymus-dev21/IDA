# IDEA Ingeniería

IDEA Ingeniería es una empresa argentina dedicada al desarrollo de soluciones electrónicas y tecnológicas. Trabaja en proyectos de seguridad vial y en desarrollos de ingeniería para distintas necesidades.

Este sitio presenta a la empresa y ofrece una visión general de sus áreas de trabajo y soluciones.

## Desarrollo

Para ejecutar el sitio localmente:

```bash
npm install
npm run dev
```

Para generar una versión de producción:

```bash
npm run build
```
